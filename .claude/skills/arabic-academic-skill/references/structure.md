# البنية: الخطة والمقدمة والفصول والملخص والخاتمة

> مرجع تفصيلي في بناء البحث الأكاديمي من الخطة إلى الفهرس. يُقرأ مع البابين ٤ و٩–١٠ من `SKILL.md`.

---

## ١. الخطة

> «خطة البحث هي الجزء الذي يرسم فيه الباحث المنهج الذي سوف يعمل خلاله البحث… وهي المشروع الهندسي لأقسام وعناصر البحث» (محجوب، ص ٤٧).

### ١.١ عناصر الخطة

```text
١. العنوان
٢. المقدمة وأهمية البحث
٣. المشكلة
٤. الأهداف
٥. الفروض (إن لزمت)
٦. حدود البحث
٧. المصطلحات
٨. المنهج
٩. إجراءات البحث
١٠. الدراسات السابقة
```

**الترتيب:** الفروض بعد الأسئلة، والحدود والمصطلحات بعد الأسئلة (سليمان، ص ٧٧). لا تُقدّم الفروض على المشكلة.

### ١.٢ نموذج خطة

```text
العنوان: أثر التنظيم الذاتي في فاعلية التعلم الإلكتروني لدى طلاب الصف الثالث الثانوي

المقدمة:
  - الإطار العام: التعليم الإلكتروني بعد ٢٠٢٠.
  - المشكلة: تفاوت النتائج رغم وحدة المنصة.
  - الأهمية: نظرياً وعملياً.
  - الفجوة: لم تُدرس العلاقة بالتنظيم الذاتي في السياق المحلي.
  - الجديد: قياس الوسيط، لا الأثر المباشر.

المشكلة: ...
الأهداف:
  ١. قياس مستوى التنظيم الذاتي.
  ٢. قياس فاعلية التعلم الإلكتروني.
  ٣. تحليل العلاقة بينهما.
الفروض: ...
الحدود: ...
المصطلحات: ...
المنهج: وصفي ارتباطي.
الإجراءات: عينة، أدوات، تحليل.
الدراسات السابقة: ...
```

## ٢. بنية الورقة (IMRaD)

### ٢.١ الأجزاء

| الجزء | السؤال | ما لا يفعله |
| :--- | :--- | :--- |
| Introduction | لماذا هذا البحث؟ | لا يعرض النتائج |
| Methods | كيف أُجري؟ | لا يفسر |
| Results | ماذا وُجد؟ | لا يناقش |
| Discussion | ماذا يعني؟ | لا يكرر الأرقام |

### ٢.٢ النسخة العربية

```text
المقدمة
المنهج والإجراءات
النتائج
المناقشة
الخاتمة والتوصيات
المصادر
```

### ٢.٣ أطوال تقريبية

| الجزء | النسبة |
| :--- | :--- |
| المقدمة | ١٠–١٥٪ |
| المنهج | ١٥–٢٠٪ |
| النتائج | ٢٥–٣٠٪ |
| المناقشة | ٢٥–٣٠٪ |
| الخاتمة | ٥–١٠٪ |

## ٣. بنية الرسالة

> «عادة ما تضم الخطة المثالية ما يلي: مقدمة، وتمهيد، وبضعة أبواب، في كل باب عدة فصول، وفي كل فصل عدة مباحث، وخاتمة وفهارس» (المرعشلي، ص ٨٠).

```text
المقدمة
التمهيد
الباب الأول: الإطار النظري
   الفصل الأول: ...
   الفصل الثاني: ...
الباب الثاني: الدراسات السابقة
الباب الثالث: المنهج والإجراءات
الباب الرابع: النتائج والمناقشة
الخاتمة والتوصيات
الفهارس
```

**قاعدة:** كل فصل يجيب عن سؤال فرعي. إن لم تجد سؤاله، فالفصل زائد.

## ٤. العنوان

### ٤.١ الشروط

> «أن يكون جامعاً لما يحتويه البحث، مانعاً من دخول غيره فيه… واضحاً تمام الوضوح… قصيراً بقدر الإمكان… موضوعياً يتحرى الحقيقة والصدق» (سليمان، ص ٧٤).

### ٤.٢ قالب

```text
[المعالجة/المتغير المستقل] + [المتغير التابع] + [العينة/السياق]
```

**مثال:** «برنامج قائم على نظرية التعلم الاجتماعي لتنمية مهارات التحدث لدى طلاب المرحلة الابتدائية» (سليمان، ص ٧٥).

### ٤.٣ جيد/ضعيف

| جيد | ضعيف | السبب |
| :--- | :--- | :--- |
| برنامج قائم على… لتنمية… لدى… | التعلم الاجتماعي وتنمية مهارات التحدث | عام، كعنوان كتاب |
| أثر… في… لدى… | دراسة تحليلية في… | غامض |
| فاعلية… في… | نحو تطوير… | دعائي |

### ٤.٤ أخطاء

- عنوان أوسع من البحث.
- عنوان أضيق من البحث.
- عنوان دعائي.
- عنوان بكلمات غامضة.
- عنوان طويل بمركبات كثيرة.
- عنوان لا يظهر في المقدمة.

## ٥. المقدمة

### ٥.١ الوظائف

1. الإطار العام.
2. المشكلة.
3. الأهمية والدوافع.
4. الدراسات السابقة بإيجاز.
5. الفجوة والجديد.
6. المصطلحات.
7. خطة البحث.

### ٥.٢ القاعدة

> «ألا يخلط الباحث بين المقدمة وبين المشكلة؛ لأن المقدمة عرض عام للموضوع والمشكلة عرض خاص» (محجوب، ص ٦١).

### ٥.٣ نموذج مقدمة (٦ فقرات)

```text
١. الإطار: من العام إلى الخاص.
٢. المشكلة: ما الذي لا يعمل؟
٣. الأدبيات: ما قيل؟
٤. الفجوة: ما لم يُقل؟
٥. الجديد: ما سأضيفه؟
٦. الخطة: كيف سأصل؟
```

### ٥.٤ أخطاء

- العمومية.
- الاقتباس الحرفي الكثير.
- تفكك الفقرات.
- غياب التسلسل.
- الإطالة بلا معنى.
- الاختصار المخلّ (سليمان، ص ٨١–٨٢).

## ٦. الملخص

### ٦.١ البنية

```text
الخلفية:    ما المعروف؟
الفجوة:     ما المجهول؟
الهدف:      ماذا يريد البحث؟
المنهج:     كيف أُجري؟
النتائج:    ماذا وُجد؟
الخلاصة:    ماذا يعني؟
الكلمات المفتاحية: ٤–٦
```

### ٦.٢ الطول

> «حجم الملخص من ٣:٥ صفحات كحد أقصى» (سليمان، ص ١٠٣) — في الرسائل. وفي الأوراق: ١٥٠–٣٠٠ كلمة.

### ٦.٣ ما لا يدخل

- الجداول.
- الاستشهادات.
- الاختصارات غير المعرّفة.
- المعلومات العامة.
- نتائج لم تُذكر في البحث.

### ٦.٤ الفرق بين ملخص البحث وملخص المؤتمر

| ملخص البحث | ملخص المؤتمر |
| :--- | :--- |
| بعد البحث | قبل البحث غالباً |
| تقرير | وعد |
| نتائج فعلية | نتائج متوقعة |
| ١٥٠–٣٠٠ كلمة | ١٥٠–٢٥٠ |

## ٧. الخاتمة

### ٧.١ العنصران

1. **النتائج:** مرقمة، كل نتيجة تجيب عن سؤال.
2. **التوصيات:** محددة، قابلة للتنفيذ، مرتبطة بالنتائج.

### ٧.٢ الطول

> «تقع عادة في حدود صفحة واحدة أو صفحتين» (المرعشلي، ص ٨١).

وفي الرسائل: «ألا تزيد على عشر صفحات في بحث يزيد على ثلاثمائة صفحة» (سليمان، ص ١٣٦).

### ٧.٣ ما تتجنبه

- إضافة نتائج جديدة.
- تكرار المقدمة.
- الوعظ.
- العموميات («يجب الاهتمام بالتعليم»).
- توصية بلا نتيجة.

## ٨. الفهارس

| الفهرس | ما يضم |
| :--- | :--- |
| المحتويات | العناوين وأرقام الصفحات |
| الجداول | أرقامها وعناوينها |
| الأشكال | أرقامها وعناوينها |
| المصادر | مرتبة وفق دليل الجهة |
| الملاحق | الأدوات، البيانات، الوثائق |

**قاعدة:** لا يُسلَّم بحث بفهرس غير مطابق. راجع العناوين بعد التنسيق النهائي.

## ٩. قائمة تحقق البنية

- [ ] الخطة تحتوي العناصر العشرة.
- [ ] العنوان جامع مانع.
- [ ] المقدمة لا تخلط بالمشكلة.
- [ ] كل فصل له سؤال.
- [ ] الملخص يعكس البحث.
- [ ] الخاتمة تجيب عن السؤال.
- [ ] الفهارس مطابقة.
- [ ] الطول وفق دليل الجهة.
